# 利用ガイド

基本の起動・操作手順は、[README](../README.md)をご覧ください。このガイドでは、声の選択や共有画面の追加・停止、設定、データの扱い、問題が起きた場合の対処方法を説明します。

## アカウントと利用枠

このアプリは、CodexにログインしているChatGPTアカウントのサブスクリプションに含まれる利用枠を使います。OpenAI APIの従量課金は使いません。APIキーでログインしている場合は音声接続を開始せず、ChatGPTへのログインを案内します。

## 起動と終了

ブラウザが自動で開かない場合は、起動時のターミナルに表示されたURLを、末尾の `#token=...` を含めてブラウザで開いてください。

起動URLには、アプリを終了するまで有効な認証情報が含まれます。他の人には共有しないでください。ページを開くと、認証情報はURLから取り除かれます。同じタブでの再読み込みはできます。アプリを起動し直した場合は、新しい起動URLから開いてください。

ブラウザのタブを閉じると画面共有と会話は終了しますが、アプリを動かしているサーバーはそのまま残ります。サーバーも終了するには、起動中のターミナルで `Ctrl+C` を押してください。

### 起動できない場合

`start.cmd`は署名のない起動ファイルのため、Windowsで「発行元を確認できませんでした」「不明な発行元」と表示される場合があります。[このリポジトリのReleases](https://github.com/apricot-cake/chatgpt-screen-talk/releases)から取得したファイルであることを確認し、実行するかどうかはご自身で判断してください。

Node.jsやCodexが見つからない場合は、ターミナルに表示された案内に従ってインストールしてください。インストール後は、もう一度 `start.cmd` を開いてください。

ChatGPTへのログインを求められた場合は、ターミナルで `codex login` を実行し、ブラウザでログインを完了してください。CodexがAPIキーでログインしている場合、このアプリから認証方法を自動で変更することはありません。

### Codexのバージョンが異なる場合

音声機能には、Codex CLI `0.164.0` を使ってください。

このアプリでは、音声AIに共有画像の読み取りとウェブ検索を許可し、ファイル操作やコマンド実行などを禁止しています。その設定が正しく働くことを確認した版に固定しているため、別のバージョンでは音声接続を開始しません。

音声接続がバージョンの不一致で止まる場合は、`codex --version` で現在の版を確認してください。上記の版をnpmで導入する場合は、次のコマンドを実行してください。

```powershell
npm install -g @openai/codex@0.164.0
codex --version
```

導入後は `start.cmd` を開き直してください。別の版が選ばれる場合は、[設定](#設定)の `CODEX_BIN` で、対応する版の実行ファイルを指定してください。

## 画面共有と音声会話

画面を共有せずに、音声だけで会話することもできます。会話の内容は文字でも表示されます。

### ウェブ検索

「ウェブで調べて」「最新の情報を検索して」などと話すと、Codexのウェブ検索を使って回答します。画面を共有していなくても検索できます。検索に失敗した場合は、その旨を伝えます。

### 声の選択と試聴

会話を始める前に、会話欄の選択メニューでSolなどの好みの声を選べます。「試聴」を押すと、選んだ声で短いサンプル音声を再生します。「停止」を押すか別の声を選ぶと再生を止めます。会話を開始したときも、試聴は自動で止まります。

試聴ではマイクや共有画像を使いません。ChatGPTに接続して音声を生成するため、試聴にも利用枠を使います。会話中に声を変更する場合は、いったん会話を終了してから選び直してください。

### 複数画面の共有

共有中は「画面を追加」から別の画面やウィンドウを追加できます。負荷を抑えるため、同時共有は4画面までです。選択をキャンセルしても共有中の画面はそのまま続きます。画面には識別名が付くので、「画面1と画面2を比べて」などと質問できます。

各画面の停止ボタンで、その画面だけを停止できます。「すべて停止」はすべての画面を停止します。AIは共有画像を取得してから回答し、画面確認の前置きを毎回発話しないよう指示しています。

### 会話のコピー

「会話をコピー」で全体を、「発言をコピー」でその発言だけをコピーできます。発話中はクリックした時点の内容をコピーします。過去の会話を読んでいる間や文字を選択している間は、末尾への自動スクロールを止めます。

### 共有と会話の終了

共有を停止しても会話は続き、会話を終了しても画面共有は続きます。両方を終える場合は、「すべて停止」と「会話を終了」をそれぞれ押してください。

### 状態の確認

「画面共有」と「会話」の見出し横にある丸い印で、状態を確認できます。灰色は未接続、黄色は準備中、緑は共有中・会話中、赤はエラーを示します。印にマウスポインターを重ねるか、キーボードでフォーカスすると、詳しい状態を表示します。

返答が聞こえない場合は、会話中の「返答音声を再生」を押してください。再生が停止した場合は自動で再試行し、ブラウザが拒否した場合は操作を案内します。音声接続や入力・受信トラックが終了した場合は、その旨を表示します。会話をもう一度開始してください。

## 設定

通常は設定を変更せずに使えます。Codexの場所や保存先などを変える場合は、起動前に環境変数を設定してください。環境変数は、起動するアプリへ設定値を渡すための仕組みです。

| 環境変数    | 設定する内容                                            | 既定の動作                                      |
| ----------- | ------------------------------------------------------- | ----------------------------------------------- |
| `CODEX_BIN` | Codexの実行ファイル、または公式の `codex.js` の絶対パス | `PATH`（コマンドの検索先）からCodexを探します。 |
| `PORT`      | サーバーが使用するポート番号                            | 空いているポートを自動で選びます。              |
| `DATA_DIR`  | 実行時データの保存先                                    | 展開先フォルダー内の `.data/` に保存します。    |

たとえば、ポート番号を指定する場合は、展開先フォルダーでPowerShellを開き、次のように実行してください。

```powershell
$env:PORT = '57259'
.\start.cmd
```

この設定は、同じPowerShellから起動するアプリに渡されます。別のウィンドウで `start.cmd` をダブルクリックしても引き継がれません。指定したポートがすでに使われている場合は、別の番号を選ぶか、設定を解除して自動選択に戻してください。

```powershell
Remove-Item Env:PORT
.\start.cmd
```

`CODEX_BIN`には、実行ファイルまで含む完全なパスを指定してください。標準的なnpmの配置にある `codex.cmd` は、自動で検出できます。独自の配置を使っていて検出できない場合は、実際の `codex.exe` または公式の `codex.js` を指定してください。

`start.cmd`で起動する場合、`DATA_DIR`の相対パスは展開先フォルダーを基準にします。

## データの扱い

### OpenAIへ送信する内容

共有画像は、このPC内で画面ごとに約1秒ごとに最新の1枚を更新します。画面に関する質問に答える際に、共有中の各画面の画像をOpenAIへ送信します。会話中のマイク音声も、回答を生成するためにOpenAIへ送信します。

ウェブ検索では、質問に基づく検索語をOpenAIの検索機能へ送信します。

### PC内に保存するファイル

既定の保存先は、展開先フォルダー内の `.data/` です。次のファイルを保存します。

| ファイル                 | 内容                                               |
| ------------------------ | -------------------------------------------------- |
| `screens/<画面ID>.jpg`   | 各画面の最後に取得した共有画像                     |
| `status.json`            | 画面共有の状態や更新時刻                           |
| `address.json`           | サーバーのURLとプロセス番号                        |
| `voice-diagnostics.json` | 音声接続の状態や受信量などの診断値                 |
| `launcher-state.json`    | 次回の起動時に準備を省略できるか判断するための情報 |

共有を停止しても、保存済みの画像は残ります。保存データを削除する場合は、アプリを終了してから `.data/` フォルダーを削除してください。次の起動時には、初回と同じ準備をやり直します。`DATA_DIR`を変更している場合は、その保存先を確認してください。

この保存先に、会話の音声ファイルや文字起こしの履歴は保存しません。このアプリの会話には、ChatGPTやCodexで開いている別のチャットの履歴は引き継がれません。

### ブラウザに保存する情報

ブラウザには、起動URLから受け取った認証情報をタブ単位の `sessionStorage` に保存します。サーバー側は認証情報をメモリ内に保持し、`address.json` や診断ファイルには保存しません。

選んだ声の名前は、ブラウザの `localStorage` に保存します。同じアドレス（ポート番号を含む）では、ページを読み直しても選択を引き継ぎます。自動選択されたポート番号が変わると、前の選択は引き継がれません。

## 確認状況と制限

2026年10月25日にCodex CLI `0.164.0` とWindowsのChromeで、検証用の画像と音声を使い、Solを選んだ接続、試聴、試聴後・会話終了後の再接続、音声認識、共有先の切り替えと画像の読み取り、返答音声の受信・ブラウザでの再生処理を確認しました。画面選択をキャンセルしても元の共有は続きます。検証時の音声出力はミュートしており、物理マイクとスピーカーを使った聞き取りは含みません。

2026年10月27日に同じCodex版とWindowsのChromeで、合成したテスト音声をWebRTCで送り、音声セッションからウェブ検索へ委譲されること、検索の実行、出典を含む回答、回答音声データの受信を確認しました。物理マイクの入力とスピーカーでの聞き取りは含みません。

2026年10月30日にChromeの検証ページで、合成テキストのコピーと貼り付け、選択中の追記による選択範囲・スクロール位置の保持、合成画面4つの同時表示、個別停止・全停止を確認しました。画像APIの隔離と複数画像の受け渡し、再生中断からの復帰は自動テストでも確認しています。実際の画面選択と複数画像を使った音声回答、長時間利用時の無音の再発有無は、この検証には含みません。

画面は必要なときに最新画像を参照する方式です。常に動画として解析するわけではなく、小さい文字やツールチップを読み違える場合があります。

Codexの共通指示（`CODEX_HOME`の`AGENTS.md`）は、このアプリの音声会話にも適用されます。

利用枠の消費量や残量は、このアプリには表示しません。関連する仕様は、[Codex App Server](https://learn.chatgpt.com/docs/app-server)と[ChatGPTの利用枠](https://learn.chatgpt.com/docs/pricing)をご覧ください。

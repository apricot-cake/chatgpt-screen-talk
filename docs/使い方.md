# 使い方・設定・データの扱い

必要な環境とダウンロード方法は、[README](../README.md)をご覧ください。このページでは、起動後の操作や設定、データの保存について説明します。

## 起動と終了

ZIPを展開したフォルダーの `start.cmd` をダブルクリックしてください。起動すると、ターミナル（処理内容が文字で表示されるウィンドウ）が開きます。初回は動作に必要なファイルをダウンロードして準備します。準備ができると、既定のブラウザでページが開きます。2回目以降は、アプリや必要なファイルに変更がある場合だけ準備をやり直します。

起動中のターミナルは開いたままにしてください。ブラウザが自動で開かない場合は、ターミナルに表示されたURLを、末尾の `#token=...` を含めてブラウザで開いてください。

起動URLには、この起動中だけ使える認証情報が含まれます。他の人には共有しないでください。ページを開くと、認証情報はURLから取り除かれます。同じタブでの再読み込みはできます。アプリを起動し直した場合は、新しい起動URLから開いてください。

終了するときは、起動中のターミナルで `Ctrl+C` を押してください。ブラウザのタブを閉じると画面共有と会話は終了しますが、アプリを動かしているサーバーはそのまま残ります。

### 起動できない場合

`start.cmd`は署名のない起動ファイルのため、Windowsで「発行元を確認できませんでした」「不明な発行元」と表示される場合があります。[このリポジトリのReleases](https://github.com/apricot-cake/chatgpt-screen-talk/releases)から取得したファイルであることを確認し、実行するかどうかはご自身で判断してください。

Node.jsやCodexが見つからない場合は、ターミナルに表示された案内に従ってインストールしてください。インストール後は、もう一度 `start.cmd` を開いてください。

ChatGPTへのログインを求められた場合は、ターミナルで `codex login` を実行し、ブラウザでログインを完了してください。CodexがAPIキーでログインしている場合、このアプリから認証方法を自動で変更することはありません。

### Codexのバージョンが異なる場合

Codex CLIは `0.164.0-alpha.11.1` で動作確認しています。他のバージョンは未確認です。現在の実装では、権限設定の確認対象をこのバージョンに絞り、それ以外では音声接続を開始しません。

`codex --version` で現在のバージョンを確認できます。対応する版をnpmで導入する場合は、次のコマンドを実行してください。

```powershell
npm install -g @openai/codex@0.164.0-alpha.11.1
codex --version
```

導入後は `start.cmd` を開き直してください。別の版が選ばれる場合は、[設定](#設定)の `CODEX_BIN` で、対応する版の実行ファイルを指定してください。

## 画面共有と音声会話

画面共有と会話は、同じページで個別に開始・停止できます。ページを開いたまま、共有したアプリに戻って作業を続けられます。

1. 「画面を共有」を押し、会話で使う画面やウィンドウを選んでください。
2. 会話欄の選択メニューで、Solなどの好みの声を選んでください。
3. 「会話を開始」を押し、ブラウザから求められたらマイクの使用を許可してください。
4. 「今の画面を見て」などと話しかけてください。会話の内容は文字でも表示されます。

共有せずに音声だけで会話することもできます。共有したアプリの音やゲーム音は取得しません。

共有中は「画面を切り替え」から別の画面やウィンドウを選べます。選択をキャンセルした場合は、元の画面を共有し続けます。声を変更する場合は、いったん会話を終了してから選び直してください。

声の横の「試聴」で、選んだ声を確認できます。「停止」を押すか別の声を選ぶと再生を止めます。試聴ではマイクや共有画像を使いません。ChatGPTに短く接続して音声を生成するため、試聴にも利用枠を使います。

「共有を停止」を押すと、画像の取得だけが止まり、会話は続きます。「会話を終了」を押すと、マイクからの音声送信が止まり、会話が終了します。画面共有はそのまま続きます。両方を終える場合は、それぞれのボタンを押してください。

### 状態の確認

「画面共有」と「会話」の見出し横にある丸い印で、状態を確認できます。灰色は未接続、黄色は準備中、緑は共有中・会話中、赤はエラーを示します。印にマウスポインターを重ねるか、キーボードでフォーカスすると、詳しい状態を表示します。

返答が聞こえず「返答音声を再生」ボタンが表示された場合は、そのボタンを押してください。音声接続が切れた場合は、いったん会話を終了してから、もう一度開始してください。

## 設定

通常は設定を変更せずに使えます。Codexの場所や保存先などを変える場合は、起動前に環境変数を設定してください。環境変数は、起動するアプリへ設定値を渡すための仕組みです。

| 環境変数    | 設定する内容                                            | 既定の動作                                      |
| ----------- | ------------------------------------------------------- | ----------------------------------------------- |
| `CODEX_BIN` | Codexの実行ファイル、または公式の `codex.js` の絶対パス | `PATH`（コマンドの検索先）からCodexを探します。 |
| `PORT`      | サーバーが使用するポート番号                            | 空いているポートを自動で選びます。              |
| `DATA_DIR`  | 実行時データの保存先                                    | 展開先フォルダー内の `.data/` に保存します。    |

たとえば、ポート番号を指定する場合は、展開先フォルダーでPowerShellを開き、次のように実行してください。

```powershell
$env:PORT = '57259'
.\start.cmd
```

この設定は、同じPowerShellから起動するアプリに渡されます。別のウィンドウで `start.cmd` をダブルクリックしても引き継がれません。指定したポートがすでに使われている場合は、別の番号を選ぶか、設定を解除して自動選択に戻してください。

```powershell
Remove-Item Env:PORT
.\start.cmd
```

`CODEX_BIN`には、実行ファイルまで含む完全なパスを指定してください。標準的なnpmの配置にある `codex.cmd` は、自動で検出できます。独自の配置を使っていて検出できない場合は、実際の `codex.exe` または公式の `codex.js` を指定してください。

`start.cmd`で起動する場合、`DATA_DIR`の相対パスは展開先フォルダーを基準にします。

## データの扱い

共有画像は、このPC内で約1秒ごとに最新の1枚を更新します。画面に関する質問に答える際に、その画像をOpenAIへ送信します。会話中のマイク音声も、回答を生成するためにOpenAIへ送信します。

既定の保存先は、展開先フォルダー内の `.data/` です。次のファイルを保存します。

| ファイル                 | 内容                                               |
| ------------------------ | -------------------------------------------------- |
| `latest.jpg`             | 最後に取得した共有画像                             |
| `status.json`            | 画面共有の状態や更新時刻                           |
| `address.json`           | サーバーのURLとプロセス番号                        |
| `voice-diagnostics.json` | 音声接続の状態や受信量などの診断値                 |
| `launcher-state.json`    | 次回の起動時に準備を省略できるか判断するための情報 |

共有を停止しても、保存済みの画像は残ります。保存データを削除する場合は、アプリを終了してから `.data/` フォルダーを削除してください。次の起動時には、初回と同じ準備をやり直します。`DATA_DIR`を変更している場合は、その保存先を確認してください。

この保存先に、会話の音声ファイルや字幕の履歴は保存しません。このアプリの会話には、ChatGPTやCodexで開いている別のチャットの履歴は引き継がれません。

ブラウザには、起動URLから受け取った認証情報をタブ単位の `sessionStorage` に保存します。サーバー側は認証情報をメモリ内に保持し、`address.json` や診断ファイルには保存しません。

選んだ声の名前は、ブラウザの `localStorage` に保存します。同じ起動先では、ページを読み直しても選択を引き継ぎます。

Codexの共通指示（`CODEX_HOME`の`AGENTS.md`）は、このアプリの音声会話にも適用されます。

## 確認状況と制限

2026年10月24日にWindowsのChromeで、検証用の画像と音声を使い、Solを選んだ接続、音声認識、共有先の切り替え、切り替え後の画像の読み取り、返答音声の受信・ブラウザでの再生を確認しました。画面選択をキャンセルしても元の共有が続くことも確認しています。物理マイクとスピーカーを使った聞き取りは、この検証には含みません。

音声機能には、Codex App Serverの試験的な機能を使用しています。Codexの更新やサービス側の変更により、利用できなくなる場合があります。

画面は必要なときに最新画像を参照する方式です。常に動画として解析するわけではなく、小さい文字やツールチップを読み違える場合があります。

このアプリでは、ChatGPTの利用枠の消費量や料金を独自に確定できません。関連する仕様は、[Codex App Server](https://learn.chatgpt.com/docs/app-server)と[ChatGPTの利用枠](https://learn.chatgpt.com/docs/pricing)をご覧ください。

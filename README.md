# hoi4-play-assistant

Hearts of Iron IVの画面を共有しながら、マイクで質問して音声で回答を聞くローカルアプリです。画面の取得と質問への回答を行い、ゲームのクリックやキー入力は行いません。ゲーム音は取得しません。

音声接続には、ChatGPTにログインしたCodex App Serverの実験的なWebRTC機能を使います。通常のOpenAI APIキーへ切り替える処理はありません。利用可否や利用枠は、アカウント・Codexの版・サービス側の提供状況に依存します。

## 必要なもの

- Node.js 22以降
- `codex app-server`を実行できるCodex CLI
- CodexでのChatGPTログイン
- 画面共有・マイク入力・WebRTCに対応したブラウザ。WindowsのChromeまたはEdgeを想定しています。

外部のnpm依存はありません。`npm install`は不要です。

## 起動

```sh
codex login
npm start
```

起動時に表示される `http://127.0.0.1:ポート番号` をブラウザで開きます。

1. 画面共有ページの「共有を開始」を押し、HOI4のウィンドウを選びます。
2. 同じアドレスの `/voice` を別のタブで開きます。
3. 「会話を開始」を押し、マイクを許可します。
4. ゲームに戻り、「今の画面を見て」などと話しかけます。

画面共有のタブは開いたままにしてください。音声ページの「終了」で音声接続を閉じ、画面共有ページの「停止」で画像取得を止めます。サーバーはターミナルの `Ctrl+C` で終了します。

### 設定

| 環境変数    | 用途                                                        | 既定値                     |
| ----------- | ----------------------------------------------------------- | -------------------------- |
| `CODEX_BIN` | Codexの実行ファイルまたは公式JSエントリーポイントの絶対パス | `PATH`から探索             |
| `PORT`      | ローカルサーバーのポート番号                                | 空いているポートを自動選択 |
| `DATA_DIR`  | 実行時データの保存先                                        | `.data/`                   |

Windowsの例:

```powershell
$env:CODEX_BIN = (Get-Command codex.exe).Source
$env:PORT = '57259'
npm start
```

Windowsの標準npm配置にある `codex.cmd` にも対応します。独自配置のshimを使う場合は、`CODEX_BIN`に実際の実行ファイルか公式 `codex.js` を指定してください。

## データの扱い

共有画像はローカルで最新の1枚を更新します。音声セッションは、画面に関する質問に答える際にその画像をツール経由で取得します。会話中のマイク音声と、参照した共有画像は、回答生成のためOpenAIへ送信されます。

`.data/`には共有画像、共有状態、接続先アドレス、音声受信の診断値を保存します。このフォルダーと画像・録音ファイルはGitの追跡対象から除外しています。認証ファイルやAPIキーをリポジトリへコピーしないでください。

このアプリの音声セッションに、開発時のチャット履歴は自動で引き継がれません。

## 確認状況と制限

元の試作では、ユーザーがマイク入力、返答音声の再生、HOI4の共有画面を参照した音声回答を確認しています。リポジトリ用に実行パスとデータ保存先を整理した版では、構文・ローカルHTTP・認証処理のmockを検証しています。整理後の版での実音声接続は別途確認が必要です。

- 音声機能は実験的なApp Serverプロトコルに依存し、互換性が変わる場合があります。
- 常時ゲームを理解する動画解析ではなく、共有画像を更新し、必要なときに参照する方式です。
- 小さい文字やツールチップを読み違える場合があります。ゲーム仕様やパッチ変更に関する回答の正確性は保証しません。
- サブスク利用枠の消費量や料金を、このアプリ独自に確定することはできません。

関連する仕様は [Codex App Server](https://learn.chatgpt.com/docs/app-server) と [ChatGPTの利用枠](https://learn.chatgpt.com/docs/pricing) を参照してください。

## 検証

```sh
npm run check
npm test
```

GitHub ActionsではWindowsとLinuxで同じ確認を実行します。CIはマイク・スピーカー・実際の画面共有・ChatGPTへの音声接続を実行しません。

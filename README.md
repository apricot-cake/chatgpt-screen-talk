# chatgpt-screen-talk

画面を共有しながら、ChatGPTと音声で会話できるWindows向けアプリです。お使いのPCで起動し、ブラウザから利用します。

![Minecraftのゲーム画面と音声会話を並べた利用画面の表示例](docs/images/screenshot.png)

## 主な機能

- 共有した画面について、音声で質問できます。
- 会話中にウェブ検索を頼み、最新の情報を調べられます。
- 画面共有と音声会話は、ブラウザ上で開始・停止できます。

共有したアプリの音声には対応していません。

## 必要な環境

- [Node.js](https://nodejs.org/en/download) 22.12以降
- [Codex CLI `0.164.0`](docs/利用ガイド.md#codexのバージョンが異なる場合) と、CodexでのChatGPTログイン
- ChromeまたはEdge

音声会話には、ChatGPTのサブスクリプションに含まれる利用枠を使います。

## インストール・起動

1. [最新版のZIP](https://github.com/apricot-cake/chatgpt-screen-talk/releases/latest/download/chatgpt-screen-talk-windows.zip)をダウンロードして展開します。
2. 展開したフォルダーの `start.cmd` をダブルクリックします。

Windowsで「発行元を確認できませんでした」と表示された場合は、[起動できない場合](docs/利用ガイド.md#起動できない場合)をご確認ください。

初回は、動作に必要なファイルをダウンロードして準備します。準備が終わるとブラウザが開きます。準備済みのファイルは、次回以降も使います。

必要なソフトウェアやログインが不足している場合は、起動時に対処方法を表示します。

起動時に開くターミナル（処理内容が文字で表示されるウィンドウ）は、利用中も開いたままにしてください。アプリを終了するときは、そのウィンドウで `Ctrl+C` を押します。

## 使い方

1. 「画面を共有」を押し、会話で使う画面やウィンドウを選びます。
2. 「会話を開始」を押し、ブラウザにマイクの利用を許可します。
3. 共有したアプリに戻り、「今の画面を見て」などと話しかけます。

利用中は、このアプリのタブを開いたままにしてください。画面共有と会話は、それぞれ「共有を停止」「会話を終了」で個別に終了できます。

マイクの音声と、回答に使う共有画像はOpenAIへ送信されます。

声の選択・試聴、共有画面の切り替え、設定、データの扱いなどの詳細は、[利用ガイド](docs/利用ガイド.md)をご覧ください。

## 利用上の注意

音声機能には、Codex App Serverの試験的な機能を使っています。Codexのバージョンやアカウント、サービスの提供状況によっては利用できない場合があります。[確認状況と制限](docs/利用ガイド.md#確認状況と制限)もご確認ください。
